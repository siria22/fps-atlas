data 폴더를 열어 시작하세요

  1. 먼저 npm run atlas -- pull로 DB를 data/atlas.json으로 뽑습니다.
  2. data 폴더 열기를 누르고 E:\projects\Web\FpsViewer\data를 고릅니다. 쓰기 권한을 물으면 허용합니다.
  3. 고칠 때마다 atlas.json에 바로 저장됩니다. "원래 값"은 뽑았을 때의 DB 값입니다.
  4. 다 고쳤으면 npm run atlas -- diff → 탭 2에서 확인 → apply로 반영합니다. 제보 처리 중에 고치면 diff를 다시 만드세요.

폴더 열기는 Chrome·Edge에서 됩니다. 탭 2(변경 검토)와 같은 폴더를 씁니다.

data 폴더를 여세요
  1. npm run atlas -- pull로 DB를 data/atlas.json·names.json으로 뽑습니다.
  2. 제보·수정 제안은 npm run atlas -- inbox, 그 밖의 수정은 두 파일을 직접 고칩니다.
  3. npm run atlas -- diff로 차이를 만듭니다(data/.review/diff.json).
  4. data 폴더 열기로 E:\projects\Web\FpsViewer\data를 고르고 변경을 고릅니다. 고를 때마다 .review/decisions.json에 저장됩니다.
  5. npm run atlas -- apply로 반영합니다(--dry-run은 SQL만).
